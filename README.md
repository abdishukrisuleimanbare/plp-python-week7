# Week 7 Assignment: My Notes & The Report Builder

## Files
- `my_notes.py` – writes, appends, reads and counts notes in a text file.
- `my_notes.txt` – the notes file generated by `my_notes.py`.
- `report_builder.py` – reads `hubs.csv` and writes a learner report.
- `hubs.csv` – sample learner data (name, hub, score).
- `report.txt` – the report generated by `report_builder.py`.

## Question
**What would happen if you changed `"a"` to `"w"` in Question 1?**
The `"w"` mode erases the file's existing content before writing, so the first three notes would be lost. The file would contain only "I added this later" and the line count would be 1 instead of 4.
